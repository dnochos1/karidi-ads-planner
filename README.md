# Karidi Ads Planner

Διαδραστικός planner διαφήμισης για το [eshop.karidi.gr](https://eshop.karidi.gr): προϋπολογισμός, διάρκεια,
κατανομή Meta/Google/TikTok, εκτιμήσεις πωλήσεων και χρονοδιάγραμμα φάσεων.

Στατικό site χωρίς build: ένα `index.html`.

## Deploy στο Vercel
1. vercel.com → Add New → Project → Import αυτό το repo.
2. Framework Preset: **Other**. Build Command και Output Directory: κενά.
3. Deploy. Κάθε push στο `main` κάνει αυτόματα νέο deploy.

Το site έχει `noindex`, ώστε να μην εμφανίζεται στο Google.
